Política de Privacidade

Aurora Local · atualizada em 11 de novembro de 2026

Quem usa

A Aurora Local é um aplicativo pessoal, usado apenas pelo próprio dono, no computador dele. Não há outros usuários.

Quais dados do Google são acessados

Com a autorização do dono, o aplicativo acessa o Gmail dele (escopos gmail.modify e gmail.send) para: buscar e ler e-mails; mover e-mails para a lixeira; arquivar; marcar como lidos; e cancelar inscrições em listas, inclusive enviando o e-mail de cancelamento que a própria lista indica. Nenhuma alteração é feita sem a confirmação do dono.

Onde os dados ficam

Os dados lidos do Gmail são processados no computador do dono, por modelos de inteligência artificial locais. As credenciais de acesso ficam guardadas criptografadas nesse mesmo computador. Nada é vendido, compartilhado com terceiros ou usado para publicidade, e nenhum dado é enviado a servidores do desenvolvedor.

Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso

O dono pode desconectar o Gmail a qualquer momento pelo próprio aplicativo (Conectores) ou em myaccount.google.com/permissions. Ao desconectar, as credenciais guardadas são apagadas.
